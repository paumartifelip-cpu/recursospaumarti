# Recursos de Vídeos — Pau Martí (YouTube)

Repositorio oficial con todos los recursos, prompts, plantillas y herramientas compartidas en los vídeos del canal de YouTube de **Pau Martí**.

---

## ⚡ Características de la Web

- **Diseño limpio y minimalista**: Sin elementos sobrecargados ni aspecto genérico de IA.
- **Recuadros 100% copiables ("Click-to-Copy")**: Cada prompt y recurso tiene su propio botón de `Copiar` con confirmación visual instantánea (`✓ ¡Copiado!`).
- **Buscador en tiempo real**: Filtra al instante por cualquier concepto, título, herramienta o texto dentro de los prompts.
- **Modo Claro / Oscuro**: Adaptable a las preferencias del usuario.
- **100% Responsive**: Optimizado para verse y copiarse cómodamente desde el móvil o el ordenador.

---

## 🌐 Activar en GitHub Pages (Gratis)

1. En este repositorio en GitHub, ve a **Settings** > **Pages** (en el menú lateral izquierdo).
2. En **Build and deployment** > **Branch**:
   - Selecciona `main`.
   - Carpeta: `/(root)`.
3. Haz clic en **Save**.
4. ¡En menos de 1 minuto tu web estará disponible públicamente para todos los espectadores de tu canal!
